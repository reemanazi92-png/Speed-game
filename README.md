# ⚡ لعبة السرعة (Speed Game)

لعبة تفاعلية تعتمد على السرعة والإجابات الجماعية للفرق، مصممة بواسطة **Firebase Realtime Database** و **GitHub Pages**.

## 🚀 المميزات
* **لوحة تحكم إدارية (`index.html`):** اختيار الأسئلة، بدء الجولات، وإعادة التصفير.
* **بنك أسئلة شاطر (`questions.js`):** يحتوي على 100 سؤال متنوع تصنيفياً.
* **واجهة إجابات فورية (`answer.html`):** إرسال الإجابات في الوقت الفعلي لكل فريق.
* **إدارة قواعد الأمان (`database.rules.json`):** حماية قاعدة البيانات باستخدام المصادقة المجهولة.

## 🛠️ التقنيات المستخدمة
* HTML5 / CSS3 / JavaScript (ES6)
* Firebase Compatibility SDK v9
* GitHub Pages Deployment
